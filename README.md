# Citewise

Chat with your documents and get answers you can trust: every answer cites its source, and it says "I don't know" when the documents don't cover the question.

## Features (planned)
- Upload PDFs or text documents
- Streaming chat answers with citations (file + page)
- Relevance threshold + grounded prompting to prevent hallucinations
- Query rewriting to handle typos and slang
- Multiple bots, with each document set kept separate
- Retrieval evals with measured accuracy

## Stack
Next.js · FastAPI · Pinecone · Groq
